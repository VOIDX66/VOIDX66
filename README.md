### :: Proyectos Destacados

#### ▸ FastFill PDF — High-Performance Document Engine & SaaS
- **Plataforma SaaS de procesamiento masivo:** Motor diseñado para inyección vectorial de datos estructurados (Excel/CSV) sobre documentos PDF base a escala, alcanzando tasas de procesamiento de hasta **~480 docs/seg**.
- **Backend & Core Engine:** API REST asíncrona y multihilo en **Rust (Axum + Tokio)** con manipulación binaria directa del árbol de objetos PDF (`lopdf`) y compresión ZIP mediante **HTTP streaming en memoria volátil** (zero disk I/O para latencia mínima y procesamiento efímero).
- **Frontend & Canvas Interactivo:** Editor SPA construido en **React 18 + TypeScript** montado sobre **PDF.js**, implementando lienzo de precisión con guías magnéticas (snapping), renderizado HiDPI y mapeo dinámico de campos vectoriales/QR.
- **Arquitectura & Cloud:** Persistencia con **PostgreSQL (SQLx)**, almacenamiento de objetos compatible con S3 en **Cloudflare R2** mediante firmas nativas SigV4, webhooks idempotentes y telemetría desacoplada con **Prometheus**.

#### ▸ Road Wear — Vehicle Lifecycle & Maintenance Tracker
- Aplicación móvil nativa desarrollada en **Kotlin** para Android orientada al monitoreo preventivo en motocicletas.
- Algoritmos para cálculo predictivo de desgaste de componentes y consumibles según tiempo de uso e historial de odómetro.
- Registro estructurado de bitácoras de servicio, alertas de inspección periódica y trazabilidad de rutas.

#### ▸ Lucy Tejada Backend
[Repositorio](https://github.com/VOIDX66/Lucy-Tejada-Back)
- API REST modular construida con **NestJS + TypeScript**.
- Persistencia y modelado de datos en **PostgreSQL / Supabase**, aplicando separación estricta de capas, DTOs y validación estricta de esquemas.

#### ▸ Cluster Storage CLI
- Herramienta de línea de comandos en **Rust** orientada a la administración y aprovisionamiento de clústeres de almacenamiento distribuido con **GlusterFS**.
- Control y gestión de volúmenes, administración de peers y monitoreo de salud de nodos en servidores Linux.
